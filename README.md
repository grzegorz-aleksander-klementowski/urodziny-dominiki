# 🎂 Urodzinowa niespodzianka

Interaktywna kartka urodzinowa — HTML, CSS i JavaScript, bez zależności.

## Publikacja przez GitHub Pages

1. Utwórz publiczne repozytorium na GitHubie (np. `urodzinowa-niespodzianka`).
2. Dodaj `index.html` do głównego katalogu repozytorium.
3. W **Settings → Pages → Build and deployment** wybierz **Deploy from a branch**, gałąź `main`, folder `/ (root)` i zapisz.
4. Po wdrożeniu strona będzie dostępna pod adresem `https://TWOJ-LOGIN.github.io/urodzinowa-niespodzianka/`.

Przed publikacją możesz edytować teksty w `index.html`. Strona nie wysyła danych ani nie korzysta z zewnętrznych bibliotek.

## Zdjęcia
Pięć fotografii umieszczono lokalnie w katalogu `photos/` (format WebP). Publikacja repozytorium jako publicznego udostępni również te zdjęcia wszystkim osobom znającym adres. Przed publikacją upewnij się, że przyjaciółka wyraża na to zgodę.
